### brandonalenz.com

This repository contains the source code for [brandonalenz.com](https://brandonalenz.com/)

---

React + TypeScript, built with [Vite](https://vite.dev/).

```sh
npm install
npm run dev      # dev server with hot reload
npm test         # vitest
npm run build    # typecheck + production build to dist/
```

Pushes to `main` build and deploy to GitHub Pages via `.github/workflows/ci.yml`.
